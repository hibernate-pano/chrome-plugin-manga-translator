# Chrome 商店审核备注（中文，可直接粘贴）

审核备注字段长度有限（约 4000 字符），以下按单一功能与权限理由组织，控制在限额内。

## 单一功能说明

```
本扩展的单一功能是：在用户主动请求时，把当前网页上的漫画/条漫图片中的外文翻译为中文，并把译文叠加显示在原图上。

不包含以下功能：广告、用户追踪、社交功能、后台常驻上传、远程代码执行、与翻译无关的页面内容抓取。

扩展不会自行翻译任何页面。用户必须通过以下三种方式之一主动触发：
1) 点击浏览器工具栏图标；
2) 在页面右键菜单选择「翻译当前页面」；
3) 手动把某个站点加入自动翻译白名单（白名单默认为空）。

安装后扩展不会自动上传任何图片内容。
```

## 权限与理由

```
权限清单与用途：

storage —— 在浏览器本地保存服务商配置、界面偏好、翻译缓存与用量统计。不使用 storage.sync，API Key 不会随 Google 账号同步到其他设备。


contextMenus —— 在页面右键菜单中提供「翻译当前页面」入口。

alarms —— 在翻译开启期间周期性唤醒后台 service worker，使其在被 Chrome 回收后重启时能重新从 storage 读取并发配置，避免长章节翻译中途 worker 重启导致队列丢失或限流参数过期。该定时器不读取也不上传任何页面数据。

host_permissions: <all_urls> —— 有两个原因：
1) 需要翻译的漫画/条漫站点无法预先枚举，用户访问的是任意网站；
2) 页面上漫画图片的 <img> 元素常被 CORS 限制、降采样或懒加载，直接在页面内把图片绘制到 canvas 无法可靠取得视觉模型所需的原始字节。后台 service worker 因此需要以 GET 方式直接向该页面自己的图床/CDN 取图。

该取图为普通 GET，请求从用户浏览器直接发往页面自身的图床，使用 credentials: 'omit'，不会携带用户在该站点的 Cookie；扩展本身不架设任何代理服务器。取图仅发生在用户已请求翻译的图片上。

content_security_policy: script-src 'self' 'wasm-unsafe-eval'
'wasm-unsafe-eval' 仅用于实例化随扩展打包的 Tesseract OCR WebAssembly 核心（本地运行，不下载远程代码）。除扩展自身的打包文件外，不允许加载任何其他脚本来源；object-src 锁定为 'self'。扩展不执行任何远程代码。

web_accessible_resources 仅声明 tesseract/* 与 content.js：
- tesseract/* ：内容脚本在页面上下文中通过 chrome.runtime.getURL() 创建 OCR Web Worker，页面上下文只能加载被声明为 web-accessible 的扩展资源。
- content.js ：构建产物中注册的 content script 是一个 loader，其实现为 import(chrome.runtime.getURL('content.js'))，若不声明则该动态导入在每个页面上都会失败。
其余内部模块（含密钥混淆模块）均未暴露，任意网页无法读取。
```

## 数据收集声明

```
本扩展不收集用户数据。

无统计、无遥测、无崩溃上报、无广告 SDK、无第三方分析 SDK、不使用 Cookie、不做用户追踪。

开发者不运行任何接收数据的服务器：不会收到用户的图片、API Key、浏览记录或翻译结果。

出站请求仅三类：
1) 用户自行配置的视觉模型服务商（翻译时上传图片）；
2) 用户正在阅读的页面自身的图床（取图，credentials: 'omit'）；
3) jsdelivr（下载 OCR 语言模型文件，不含任何图片或页面内容）。

API Key 仅保存在本机 chrome.storage.local，以固定盐值 XOR 混淆后写入（这是混淆而非加密，用于避免在存储查看器中一眼可读，不作为安全边界）。
```

## 供审核参考的测试方式

```
仓库根目录的 smoke-test-page.html 是自包含测试页（图片内联生成，可离线 file:// 打开），包含：中英日韩气泡、4000px 长条漫、跨域图片、应当被跳过的内容（页眉 logo、小于 200px 的图）。

审核者可用如下步骤验证扩展的核心功能：
1. 安装扩展，按弹窗引导完成设置。
2. 配置任一 OpenAI 兼容服务商（base URL + model + API Key），点击「测试配置」确认连通性验证生效（错误 Key 会报鉴权失败，错误 base URL 会报无法连接）。
3. 用 file:// 打开 smoke-test-page.html，点击工具栏图标。
4. 预期：第 1 栏两个气泡、第 2 栏条漫四个气泡、跨域图片均被翻译；第 4 栏内容被跳过。
5. 再次翻译同一页面（启用缓存）预期不再发出任何服务商请求。
6. 切换服务商或模型后，缓存不被复用。
7. 打开未加入白名单的普通网站，确认扩展不会自动翻译。
```

## 容易被问到的问题

| 问题 | 回答 |
| --- | --- |
| 为什么需要 `<all_urls>`？ | 目标站点无法预先枚举，且需从页面自身的图床取图。见「权限与理由」。 |
| 为什么不只申请用户主动点击时的 `activeTab`？ | `activeTab` 只授予当前标签页的一次性权限，不足以在自动翻译模式下于页面加载后取图。 |
| 是否会远程加载代码？ | 不会。`'wasm-unsafe-eval'` 仅用于本地打包的 WASM 核心，其余脚本来源锁定为 `'self'`。 |
| 是否上传浏览历史？ | 不会。只有用户请求翻译的图片会发往其自行配置的服务商。 |
| API Key 存储安全吗？ | 本地 `storage.local` + XOR 混淆。这是混淆不是加密，文案与隐私政策均如实说明，未声称加密。 |
| 是否使用远程服务器中转图片？ | 没有。取图为浏览器直连页面自身图床的 GET，开发者无服务器。 |
